# Presentation Coaching

This skill guides the user in transforming static slide content into a dynamic presentation. It focuses on the transition from "what is on the slide" to "what the speaker says."

## Procedure

1. **Analyze Content**: Extract key themes, target audience, and core objectives from the slides/document.
2. **Determine Delivery Style**: Ask or suggest a style based on the context:
    - **Professional/Academic**: Structured, authoritative, clear, and formal.
    - **Persuasive/Pitch**: Energetic, high-impact, value-driven, and concise.
    - **Casual/Relatable**: Story-driven, conversational, and engaging.
3. **Develop a Script**: For each slide, provide:
    - **Visual Anchor**: What the audience is seeing.
    - **Spoken Script**: Exact wording or suggested phrasing for the speaker.
    - **Delivery Note**: Guidance on tone, pacing, or body language.
4. **Add Engagement Elements**: Suggest hooks, rhetorical questions, or physical props to keep the audience focused.
5. **Final Polish**: Review for flow, transitions between slides, and time management.

## Pitfalls

- **Reading the Slide**: Never write a script that simply repeats the text on the slide. The speaker must add value beyond the bullet points.
- **Uniform Pacing**: Avoid a monotone delivery. Ensure the script has peaks (excitement) and valleys (serious/reflective) to maintain attention.
- **Over-scripting**: Do not provide a verbatim script that feels robotic. Provide "guidance blocks" that allow the user's personality to show.
- **Ignoring the Hook**: A presentation without a strong opening hook is quickly forgotten. Always prioritize a compelling start.

## User Preferences
- Prefer structured "Slide by Slide" breakdowns.
- Provide multiple style options (e.g., "The Pitcher" vs. "The Academic") if the context is ambiguous.
